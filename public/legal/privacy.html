Privacy policy

Last updated: November 1, 2026. Version française

A Studio is a music production app published by Kurodaki. This page explains what data the app handles and what it does with it.

Summary

  • The app collects no personal data.
  • No account, no ads, no analytics.
  • Its only connections go to GitHub: checking for a new version of the app (can be turned off), downloading it when you accept, and installing plugins from a GitHub link you enter. They send nothing about you.
  • Your projects, samples, plugins and themes stay on your device.

Data stored on your device

This data never leaves the device and we have no access to it. You can erase everything from Android settings (Apps, A Studio, Storage, Clear data) or by uninstalling the app.

Update check

At startup the Android app asks GitHub for the latest published version (api.github.com/repos/kurodaki-dev/A-studio/releases/latest). The request contains no identifier, no cookie and nothing about your projects or device. Like any internet connection, GitHub receives the phone's IP address, which it handles under its privacy statement. We receive nothing.

If a newer version exists, the app offers it. The download only starts when you tap Download: the app fetches the APK from this project's GitHub releases, then opens the Android installer, which asks you to confirm. Only release addresses of this project are accepted.

You can turn off the startup check in Settings. The manual check stays available.

Installing from GitHub

When you open the plugin catalog, the app downloads its list from the A Studio repository (raw.githubusercontent.com). When you paste a link in Install from GitHub, or tap Update from GitHub, the app asks GitHub for that repository's file list (api.github.com) and downloads the files you choose (raw.githubusercontent.com). The requests contain the link you entered and nothing about you; GitHub receives the phone's IP address, as for any connection. Nothing is sent without your action.

Files you export or import

When you export a WAV or project file, the app opens the Android share menu and you choose where the file goes. The app sends nothing by itself; the service you pick applies its own privacy policy.

When you import a project, audio files, a ZIP pack, a plugin or a theme, the app only reads the files you select and copies them into its storage on the device.

Plugins and themes

Plugins and themes are files you choose to install and they stay on your device. A theme only contains colors. Instrument and effect plugins are JavaScript code that runs only in the audio thread (AudioWorklet), with no access to the app interface, your projects, your samples, your files or the network: they receive notes or sound and return sound. Extension plugins run in an isolated frame with no access to the app page or its storage; they can only use the app features they declare in their header (interface, playback, reading or writing the open project), and the app shows these permissions in Settings.

Bug reports

The Report a bug button opens this project's new issue page on GitHub in your browser, with the app version filled in. Nothing is sent until you submit the issue yourself, and what you submit is public on GitHub.

Android permissions

The app does not access the microphone, contacts, location or your files (other than those you choose to import). It declares the standard network permission, used only to check for and download updates; its Content Security Policy blocks every other connection from the interface. It also declares the permission to install apps, used only to open the Android installer with a downloaded update; Android asks you to allow it the first time.

Website on GitHub Pages

These pages and the web version of the app are hosted by GitHub Pages. The web version works like the app: projects are stored in your browser and sent nowhere. As the host, GitHub may process technical connection data such as IP addresses to run and secure the service, under its own privacy statement.

Children

The app collects no data from anyone, children included.

Your rights

Under the GDPR you have rights of access, rectification and erasure. Since we hold no data about you, there is nothing to send or delete on our side. Data on your device is under your control. You can also file a complaint with your data protection authority (in France, the CNIL: cnil.fr).

Changes

If the app changes how it handles data, this page is updated before the new version is published, with a new date at the top.
