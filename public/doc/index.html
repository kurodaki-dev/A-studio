A Studio documentation

A music production studio for Android, built on the FL Studio workflow: channel rack, piano roll, playlist, mixer and a browser for your samples.

Download the APK Try the web version

Install

  1. On your phone, download A-Studio.apk from the latest release.
  2. Open the file. Android asks you to allow installs from your browser or file manager the first time.
  3. A Studio runs in landscape and full screen. Swipe from an edge to show the system bars.

Requirements: Android 7.0 (API 24) or newer. The app keeps itself up to date, see Updates.

Interface

The top bar holds the menu (three lines), the PAT and SONG modes, play, stop, metronome, tempo, the position display (bar:step:tick), the current pattern and undo/redo. The rail on the left opens the browser and switches between the playlist, channel rack, piano roll and mixer.

Knobs and faders move with a vertical drag. A double tap resets them. The current value shows in the hint bar at the top right on wide screens.

Channel rack

  • Each row is a channel: enable light, pan, volume, mixer insert, name and 16 steps per bar.
  • Tap a step to turn it on; drag across steps to fill or clear several.
  • The name button opens the channel menu: piano roll, settings, rename, clone, move, delete.
  • A channel holding piano roll notes shows a preview instead of steps. Tap it to open the piano roll.
  • The plus and minus buttons in the rack header add or remove bars from the pattern.

Piano roll

The piano roll follows FL Studio. Notes are named like FL Studio: middle C is C5.

  • A long press on a note deletes it (the mouse right button does the same).
  • Scroll with the scrollbars at the bottom and right, with two fingers, or with the Pan view tool. Pinch to zoom: horizontally or vertically depending on how you hold your fingers.
  • Notes from the other channels show as ghost notes. The velocity lane edits note velocity.
  • Snap goes from 1/6 step to a full bar, or off.
  • Toolbar actions: copy, paste, duplicate, delete selection, transpose by a semitone or an octave, quantize, select all.

Playlist

  • PAT plays the current pattern, SONG plays the playlist.
  • With the Draw tool, tap an empty spot to place the current pattern. Tap a clip to make its pattern current. Drag a clip to move it, long press to delete it.
  • Stretch a clip by dragging its right edge. A stretched pattern clip repeats its pattern; an audio clip is cut or extended with silence.
  • Tap a track name to mute the track.

Mixer

The master and 16 inserts each have a fader (0 dB at 80%), pan, reverb and delay sends, mute, solo, a level meter and an FX button with 4 slots for effect plugins. Route a channel to an insert from the insert number in the channel rack or from the channel settings.

Browser and samples

  • Open or close the browser with the top button of the left rail (F8 on a keyboard). It has a search field and folders for projects, your samples, plugins and built in sounds.
  • The import button accepts audio files (WAV, MP3, OGG, FLAC, M4A, AIFF) and ZIP sample packs. Folders inside a pack are kept. Samples are stored on the device only.
  • Tap an item to preview it. To drop it somewhere, drag it to the right or long press it, then move it:
    • onto a playlist track: it becomes an audio clip with its waveform;
    • into the piano roll: a Sampler channel is created and a note is placed where you let go;
    • into the channel rack: a Sampler channel is created.
  • The Sampler plays the sample at its own pitch on C5 and transposes it on other notes.

Projects and export

  • The open project is saved automatically. Use Save or Save as to keep named projects on the device.
  • Export project file writes a .astudio file you can share or back up. It does not contain imported samples: import the pack again on another device.
  • Export as WAV renders the pattern (PAT mode) or the song (SONG mode) as 16 bit, 44.1 kHz stereo.

Settings and language

Menu, Settings. The interface is in English by default and also available in French. Settings also hold the theme, plugins, the update check, the documentation link and the bug report button.

Updates

Every change published on the main branch builds a signed APK and a new release (v1.0.<number>). At startup the app checks the latest release and offers it. Tap Download: the app downloads the APK, then Android shows its installer and asks you to confirm. Android requires that confirmation and the first time also asks you to allow A Studio to install apps. When the install finishes, tap Open to restart A Studio on the new version. Projects are kept.

The startup check can be turned off in Settings. Menu, Check for updates, checks by hand.

Plugins

A plugin is a JavaScript file. There are two kinds:

  • Instruments generate sound for notes, sample by sample: oscillators, filters, envelopes, physical models, anything you can compute. They appear in the browser under Plugins and work like any instrument: channel rack, piano roll, playlist, WAV export.
  • Effects (@type effect) process the sound of a mixer insert: distortion, delay, filters, compressors. Each insert has 4 effect slots behind its FX button.

Install a plugin from Menu, Plugins and themes, Install a plugin, or write one directly on the phone with Write a plugin: the editor has an instrument template and an effect template, checks the header as you go, installs the plugin and plays a test chord, and exports the file to share it. Installed plugins can be edited again with the pencil button.

Where the code runs

Plugin code runs only inside an AudioWorklet, the audio thread of the app. That scope has no access to the interface, to storage (projects, samples, settings), to the network or to files: a plugin receives notes and parameter values and returns samples. The host also protects the app:

  • an exception in a voice removes that voice and shows the error once, the app keeps running;
  • output is limited to ±4 and NaN values become silence;
  • 32 voices at most per channel, and a voice still playing 10 seconds after its note off is cut.

A plugin can still use a lot of CPU and make the sound stutter. Install plugins from people you trust.

A minimal plugin

/**
 * @astudio-plugin
 * @id simple-sine
 * @name Simple Sine
 * @version 1.0.0
 * @author Your name
 * @category synth
 * @param release "Release" 0.01 2 0.3
 */
class SineVoice {
  // Called when a note starts.
  constructor({ key, frequency, velocity, sampleRate, params }) {
    this.step = frequency / sampleRate;
    this.phase = 0;
    this.gain = 0.2 * velocity;
    this.sr = sampleRate;
    this.releasing = false;
  }

  // Called when the note ends (optional).
  noteOff() {
    this.releasing = true;
  }

  // Fill left and right (Float32Array, up to 128 samples, already zeroed).
  // Return false when the voice is finished.
  process(left, right, params) {
    for (let i = 0; i < left.length; i++) {
      if (this.releasing) this.gain *= Math.exp(-1 / (params.release * this.sr));
      const s = Math.sin(2 * Math.PI * this.phase) * this.gain;
      this.phase = (this.phase + this.step) % 1;
      left[i] = s;
      right[i] = s;
    }
    return !(this.releasing && this.gain < 0.0001);
  }
}

registerVoice(SineVoice);

GlobalsStandard AudioWorklet globals are available: sampleRate, currentFrame, currentTime, Math. No fetch, no DOM, no storage.

A file is limited to 256 KB. Use plain JavaScript in one file; import of other files is not available.

Effects

/**
 * @astudio-plugin
 * @id soft-clip
 * @name Soft Clip
 * @type effect
 * @param drive "Drive" 1 20 4
 */
class SoftClip {
  constructor({ sampleRate, params }) {}

  // inL, inR: input samples. Write the result in outL, outR.
  process(inL, inR, outL, outR, params) {
    for (let i = 0; i < inL.length; i++) {
      outL[i] = Math.tanh(inL[i] * params.drive);
      outR[i] = Math.tanh(inR[i] * params.drive);
    }
  }
}

registerEffect(SoftClip);
ItemDescription
registerEffect(EffectClass)Required for effects. One instance per slot.
constructor({ sampleRate, params })Called when the effect is placed in a slot.
process(inL, inR, outL, outR, params)Called for every block of 128 samples. Read the input, write the output.
button(id, params)Optional. Called when a @button is pressed.

If an effect throws an error, its slot lets the sound through unchanged and the error is shown once.

Examples

  • poly-synth.astudio-plugin.js: resonant filter synth that uses every control type: choice, knobs, switch and button.
  • stereo-delay.astudio-plugin.js: effect, delay with feedback, tone, ping pong switch and a Clear button.
  • bitcrusher.astudio-plugin.js: effect, bit depth and sample rate reduction.
  • supersaw.astudio-plugin.js: seven detuned saws, filter and envelope, three knobs.
  • fm-bell.astudio-plugin.js: two operator FM bell.
  • noise-snare.astudio-plugin.js: a one shot drum made of a tone and filtered noise.

Projects store plugin channels as plugin:<id> with their knob values. If the plugin is missing on a device, the channel stays silent until you install it.

Themes

A theme changes the colors of the interface and of the editors. It only contains hex colors (#rgb or #rrggbb); anything else is ignored. Missing keys fall back to the default theme. Install one from Menu, Plugins and themes, Install a theme. Three themes are built in: A Studio, Graphite and Daylight.

Privacy

A Studio collects no personal data. Projects, samples, plugins and themes stay on the device; plugin code runs isolated in the audio thread. The only connection checks GitHub for a new version and downloads it when you accept. Details: privacy policy, terms of use, cookie policy.

Building from source

Requirements: Node.js 22, JDK 21 and the Android SDK (platform 36).

git clone https://github.com/kurodaki-dev/A-studio.git
cd A-studio
npm install
npm run dev            # web version on http://localhost:5173
npm test               # unit tests
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug

Found a problem? Open a bug report. An idea? Request a feature. Both are also in the app menu.
